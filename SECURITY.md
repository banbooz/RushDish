# Security Policy

## Supported versions

RushDish is currently a prototype. Security fixes are applied only to the
latest version on the `main` branch.

## Report a vulnerability

Do not disclose vulnerabilities in a public issue, discussion, pull request,
or screenshot.

Use GitHub's private vulnerability reporting form:

https://github.com/banbooz/RushDish/security/advisories/new

Include the affected page or component, reproduction steps, potential impact,
and any suggested mitigation. Remove credentials, personal data, payment data,
and unrelated confidential information from the report.

The maintainer will review the report, ask for any required clarification, and
coordinate disclosure after a fix is available when the report is accepted.
