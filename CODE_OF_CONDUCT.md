# Code of Conduct

## Our standard

RushDish welcomes constructive, respectful participation. Be considerate of
different backgrounds and levels of experience. Focus feedback on the work,
avoid harassment or personal attacks, and do not publish another person's
private information.

## Unacceptable behaviour

Unacceptable behaviour includes intimidation, discriminatory language,
unwanted sexual attention, sustained disruption, threats, doxxing, and any
conduct that would make a reasonable participant feel unsafe or unwelcome.

## Enforcement

The repository owner may edit or remove contributions that violate this code
and may temporarily or permanently restrict participation when necessary.

Use GitHub's platform reporting tools for abusive content. For other conduct
concerns, contact the repository owner through their GitHub profile without
posting sensitive details publicly.
